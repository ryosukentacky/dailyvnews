# GitHub Pages ニュース専用・操作機能再現版

- 日付: 2026-10-22
- 13テーマ、15解説カード。ニュース解説以外のチャットやアップロード方法のやり取りは非表示。
- 7種類のスライダー（改装費・家賃の2本連動を含む）、3つのグラフ、市場データの黒いカードを再現。
- 元HTMLから抽出したニュース解説本文は書き換えずに保存。チャット固有の動作はHTML/CSS/JavaScriptで別実装。
- 理解確認の設問と解答は元HTMLに含まれる文章を保持しています。答えの位置がHTMLで判別できるものだけ開閉表示に変換します。判別できない場合はそのまま表示されます。
- **画像**: 提供HTMLから抽出できた画像のみ同梱。元記事にあったがエクスポートに保存されなかった写真は復元できません。assets内にある画像はUIアイコンやアバターの可能性があるためニュース写真と誤認しないよう本文に自動挿入していません。

## 公開
ZIPを解凍し、すべてのファイルを同じディレクトリに置いてGitHub Pagesで公開します。すでにサイトがある場合は `news/2026-10-22/` のような**別フォルダ**に置いてください。

GitHubのUpload filesがエラーになる場合は **GitHub Desktop** からコミット・Pushする方法を推奨します。複数のJSONファイルに分割しているため、個別アップロードもしやすい構成です。

**制約**: 画像とUIの完全一致は元エクスポートの情報量に依存します。数値計算は学習用の再実装です。
